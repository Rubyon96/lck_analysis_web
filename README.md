# LCK Analysis Web

## Project Purpose

리그오브레전드 LCK 경기에 대한 분석 웹페이지를 빠르게 프로토타입으로 제작한다.

## Current Scope

현재 단계에서는 프로젝트 기본 폴더 구조와 개발 규칙을 먼저 정리한다.

## Development Direction

- 빠른 프로토타입을 우선한다.
- 함수형 프로그래밍 스타일을 선호한다.
- 외부 라이브러리는 최소화한다.
- 작은 단위로 만들고 검증한다.
- 요청한 작업 외의 임의 추가 작업은 하지 않는다.

## Folder Rules

- planning: 기획, 개발 규칙, 작업 계획
- data: 원본 데이터, 분석용 데이터, 샘플 데이터
- app: 실제 웹페이지 파일
- app/data: 웹페이지가 직접 사용하는 가공 데이터
- validation: 체크리스트, 검증 결과
- archive: 더 이상 사용하지 않지만 보관할 자료

## Next Step

샘플 경기 데이터와 기본 웹페이지 파일을 만들기 전에 필요한 화면 범위를 정한다.
